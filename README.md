# BADANG Trading 1.0

Bitget USDT 무기한 선물 종목 전체를 대상으로 기술적 지표를 스캔하는 모바일 웹 프로토타입입니다. **자동 주문을 하지 않습니다.**

## 실행

Python 3.10 이상이 설치된 컴퓨터 또는 서버에서:

```bash
pip install -r requirements.txt
python app.py
```

휴대전화에서 사용하려면 이 프로젝트를 Python을 지원하는 웹 서버에 배포하고 해당 서버의 HTTPS 주소로 접속합니다. 로컬 컴퓨터에서 실행하면 기본 주소는 `http://127.0.0.1:5000`입니다. 이 주소는 컴퓨터 내부에서만 접속됩니다.

## 기능

- Bitget 공식 공개 API의 `contracts`, `tickers`, `candles` 조회
- 정상 거래 중인 USDT 무기한 선물 종목 자동 검색
- 24시간 거래대금 기준 필터 및 15분·1시간·4시간·일봉 선택
- 확정 캔들로 EMA20/50, RSI14, MACD12/26/9, 거래량 변화, 20봉 돌파 평가
- 65점 이상 롱/숏 후보만 기본 목록에 표시, 관망 종목도 필터로 확인
- 신호 근거, 최근 20봉 지지/저항 구간 표시
- API 실패 건수 및 스캔 진행 상황 표시

## 중요 한계

- 현재는 과거 성과 검증 전의 **휴리스틱 신호**입니다. 점수는 승률이나 수익 확률이 아닙니다.
- 전체 종목 스캔은 종목 수에 따라 수십 초~수분이 걸릴 수 있습니다. 서버 재시작 시 진행 중 작업이 소실됩니다.
- 거래대금이 낮은 종목도 포함하려면 '전체 종목' 필터를 사용하세요.
- 다이버전스, 다중 시간봉 합의, OI 변화, 백테스트, 푸시 알림, 서버 스케줄러는 다음 단계에서 추가할 기능입니다.
- 공개 API 응답 형식이나 거래소 정책이 변경되면 코드 수정이 필요합니다.
- API 키, 주문 권한, 자동 거래 기능은 사용하지 않습니다.
